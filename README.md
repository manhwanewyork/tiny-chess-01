# Tiny Chess Engine

A 4KB Python chess engine for the [make.fun tiny-chess-01 bounty](https://make.fun/bounty/tiny-chess-01): alpha-beta + quiescence, transposition table, killer moves, MVV-LVA, iterative deepening, fixed 50,000 nodes/move. `main.py` is a compressed (lzma) entrypoint, 4,045 bytes.
